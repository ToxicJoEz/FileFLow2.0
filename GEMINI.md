# Permanent Safety Rule: Git Push

**CRITICAL INSTRUCTION**: NEVER run `git push` or push code to a remote repository automatically. 
You are strictly forbidden from pushing code unless the user explicitly commands you to do so (e.g., "push this to github" or "you have my permission to push").
If the user asks you to make commits or prepare a repository, you may run `git init`, `git add`, and `git commit`, but you MUST STOP before pushing and ask the user to manually execute `git push` themselves, or ask for their explicit permission to run it on their behalf.
